# BestPaints Survey

Локальное приложение замерщика для покраски деревянных домов ([BestPaints](https://www.bestpaints-bp.ru/)).

## Запуск

```bash
cd ~/Projects/bestpaints-survey && ./start.sh
# http://127.0.0.1:8765/
```

PWA: Safari → Поделиться → На экран «Домой».

## Что умеет

1. Несколько строений + шаблоны + дублирование  
2. Плоскости: прямоугольник / фронтон / трапеция / своя площадь  
3. Живая формула листа: `Sобщ = (Sст − Sок + Sтор) × K`  
4. **Калькулятор «По проекту»** (масштаб как в обучении: 3,35÷4,5→K)  
5. Обсады у проёмов, габариты дома, душ/email/замерщик  
6. Готовность %, фото, цвет на схеме, PDF, Telegram/WhatsApp  
7. Шпаргалка обучения в приложении  

Сверка с видео и листом: [`docs/TRAINING_GAP.md`](docs/TRAINING_GAP.md)
