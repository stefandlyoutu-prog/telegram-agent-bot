# BestPaints CRM — воронка замеров (Лидоруб)

## Логика

1. **Лидоруб** в Telegram (`/zamer`): название сделки, квалификация, адрес, дата замера, аудио.
2. Система смотрит **график** замерщиков на дату. Пусто → статус «Создана» + алерт админу.
3. Есть кто в графике → **Замер назначен** + SMS «взять в работу».
4. Замерщик: **Взял в работу** → за день до даты SMS подтвердить выезд → **Выезд подтверждён**.
5. На адресе: **Начинаю замер** → конструктор **с шага «Строение»** (данные сделки уже есть).
6. В конце: **Заключил** / **Не заключил** + чек-лист (ссылки фото/видео/ТЗ).
7. Не заключил → автоматически **менеджеру из графика** (защита ТЗ).

## Исправления статусов в веб

В карточке сделки блок «Исправить статус / удалить»:
- сменить статус вручную
- **Вернуть в работу**
- **Удалить** (скрыть из списка)

## Команды бота

- `/zamer` — Лидоруб
- `/grafik`, `/grafik_add`, `/grafik_clear`, `/bp_staff` — админ
