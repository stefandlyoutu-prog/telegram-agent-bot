# BestPaints CRM — требования из записи «Новая запись 39»

Источник: `/Users/polzovatel/Downloads/Новая запись 39.m4a` (~5.8 мин).

## Как понял процесс

Роли: **ледоруб** (назначил замер), **замерщик**, **менеджер**.

1. Ледоруб договорился о замере → создаёт **объект** в приложении (больше не писать вручную в группу «выезда»).
2. При создании — **назначение замерщика по адресу** (распределение зон/адресов).
3. Замерщику уходит **SMS** (карточка объекта).
4. Замерщик жмёт **«Взял в работу»** → статус/цвет меняется → ледоруб спокоен.
5. Если **~2 часа** не взял → SMS/оповещение ледорубу + тег/эскалация.
6. Замерщик созванивается → **«Выезд подтверждён»** → статус + оповещение ледорубу.
7. **«Приехал на объект»**.
8. **Создание сметы** — открывает конструктор/замер (наш Survey) внутри объекта.
9. Заполняет строения/смету + данные договора.
10. Развилка:
    - **Договор заключён** → «Подписанные договоры» + авто-пост в Telegram-группу + оповещение.
    - **Не заключён** → назначить менеджера → оповещение «бери в работу».
11. Замерщик заполняет **чек-лист** (разный: заключили / не заключили).
12. Менеджер **«Взял в работу»** → цепочка закрыта.

### Статусы

`created` → `assigned` → `accepted` → `visit_confirmed` → `on_site` → `estimate_done` → `contract_signed` \| `contract_declined` → (`manager_assigned` → `manager_accepted`) → `closed`

### Env (Render)

- `BESTPAINTS_DB_PATH` — лучше `/var/data/bestpaints_crm.db`
- `BESTPAINTS_TG_BOT_TOKEN` — бот для постов
- `BESTPAINTS_TG_CHAT_SIGNED` — чат «подписанные договоры»
- `BESTPAINTS_TG_CHAT_OPS` — общий ops-чат
- `BESTPAINTS_SMS_URL` — URL шлюза с `{phone}` и `{text}`
- `BESTPAINTS_ESCALATION_HOURS` — по умолчанию 2
