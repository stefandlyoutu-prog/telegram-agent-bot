2. Бот — сразу /start

В личке боту напишите /start — придёт вся шпаргалка команд.

/start — команды и настройка /grafik_fill — поставить ВСЕХ в график на сегодня (кнопки) /grafik — кто сегодня в графике /bp_staff — ID замерщиков/менеджеров /zamer — новая сделка (Лидоруб) /chatid — в группе Ops / Подписанные

3. Как заполнить календарь (график)

Без графика сделка НЕ назначается замерщику (статус «Создана»).

  1. Сайт → вкладка «Команда»: добавьте людей (Имя + @ник Telegram).
  2. Каждый пишет боту /start — появляется «связан».
  3. Сайт → вкладка «График»: нажмите чипы имён (в смене = золотые).
  4. Или бот: /grafik_fill.

4. Полный цикл за 10 минут

  1. /grafik_fill на дату замера.
  2. /zamer → название → квалификация → адрес → дата → клиент → аудио или «готово».
  3. Должно стать «Замер назначен» + имя замерщика. Ссылка в ответ.
  4. Откройте кабинет по ссылке (или список CRM).
  5. Кнопки по порядку: Взял в работу → Выезд подтверждён → На адресе → конструктор.
  6. Заключил → сообщение в группу «BP Подписанные» · чек-лист ссылок.
  7. Не заключил → автоматически менеджер из графика (защита ТЗ).

5. Группы (3 человека)

  • BP Ops — лента статусов / алерты (график пуст, назначения).
  • BP Подписанные — только договоры.
  • Если бот молчит в группе: в группе напишите /chatid.

6. Если что-то «сломалось»

  • Сделка «Создана» без замерщика → график на дату замера пуст → /grafik_fill ДАТА → в карточке «Назначить из графика».
  • Старый PDF / UI → жёсткое обновление (Cmd+Shift+R) или зеркало onrender.
  • Не та кнопка → в карточке «Исправить статус / удалить».
  • SMS пока stub (шлюз не подключен) — пуши идут в Telegram Ops.

7. Чек-лист перед разбором

  • □ Войти в кабинет
  • □ /start в боте — видна шпаргалка
  • □ /grafik_fill — график не пустой
  • □ /zamer тестовая сделка → назначен замерщик
  • □ Пройти статусы до «на адресе»
  • □ Открыть конструктор ЛКМ
  • □ Заключил / не заключил → проверить Ops и Подписанные
