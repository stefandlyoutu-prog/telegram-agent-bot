# Эталон замера ↔ BestPaints Survey

Сверка с отраслевой практикой ([paintpricing.com](https://paintpricing.com/how-to-measure-a-house-for-exterior-paint/), [kronid55.ru](https://kronid55.ru/metering-facade)) и листом осмотра ДД / обучением BestPaints.

## Как делают профессионалы (шаги)

1. Обход по периметру / по часовой  
2. Каждая стена: длина × высота (+ фронтон / треугольник)  
3. Вычесть проёмы (окна, двери, ворота)  
4. Допы: подшива, лобовая, торцы, наличники, шов  
5. Состояние / материал → технология и ЛКМ  

## Как у нас

| Эталон | Наш шаг |
|--------|---------|
| Проект / адрес | Проект |
| Тип объекта | Строение |
| Стены по кругу | Замер (выбор стороны + размеры + фото) |
| Проёмы | Проёмы |
| Soffit / trim / шов | Допы |
| Технология | Конструктор |
| Быт / договор / смета | Договор → Смета |

Формула листа: `Sобщ = (Sст − Sок + Sтор) × K` — живая в UI.

Плоскости (не только периметр×высота) — точнее для дерева и ломаных крыш.

## UX сторон (как SmartDraw по смыслу)

- Чипы сторон + клик по грани схемы  
- Одна активная сторона в фокусе, остальные свёрнуты  
- Создать / выбрать / править сразу  
- Полный контур «по точкам» как CAD — не нужен для полевого замера; достаточно плоскостей
