# Чек-лист замерщика → где в приложении

Типичные ситуации на объекте BestPaints и куда вносить.

| Ситуация | Шаг | Поле / как |
|----------|-----|------------|
| Новый объект | Проект | Название, клиент, адрес |
| Дом / баня / гараж / забор | Строение | Тип |
| Забор с двух сторон | Строение | «Красим с двух сторон» → площадь ×2 |
| Цоколь камень — не красим | Строение | Чекбокс + заметка |
| Стороны по кругу | Замер | Чипы / схема / размеры / фото |
| Комментарий к стороне | Замер | Текст под размерами |
| Гниль, отслоение, высота, мебель | Замер | Флаги + площадь ремонта |
| Окна / двери | Проёмы | W×H, сторона, шов, комментарий |
| Подшива, лобовая, свесы | Допы | м² |
| Крыльцо, лестница | Допы | м² → смета |
| Наличники, водосток, отливы, балки | Допы | пог.м → смета |
| Тёплый шов | Допы (+ авто из проёмов) | разбивка |
| Влажность, цвет, снятие покрытия | Конструктор | % / заметка / сложность |
| Технология и ЛКМ | Конструктор | матрица |
| Леса / вышка / подъёмник | Договор | доступ → в смету |
| Высота, подъезд | Договор | м + заметка |
| Электричество / генератор | Договор | кВт + хватит? |
| Живут / мебель | Договор | селекты |
| Светильники, батареи, кондеи, трубы | Договор | счётчики → «в доп.услуги» |
| Каталог допов | Договор | все группы |
| Разовая позиция | Смета | «Свои позиции» |
| PDF клиенту | Смета | стороны, проёмы, комментарии |

## Что программа учитывает в сумме

- Площади стен (с K, фронтонами, ×2 для забора)
- Проёмы (−), торцы, подшива, лобовая, свесы, крыльцо, лестница, ограждения
- Наличники / доборы / раскладка / водосток / отливы / балки
- Тёплый шов, ремонт по флагам, надбавка за высоту стороны
- Доп.услуги и свои позиции
- Оценка лесов/вышки с шага «Договор»
- НДС 5%, скидка, этапы оплаты
