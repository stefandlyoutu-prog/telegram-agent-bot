# Конструктор smeta-bestpaints.ru (изучение, без правок)

Доступ только по выдаче администратора. Учётные данные в этот файл и в репозиторий **не писать**.

## Структура (3 шага)

1. **Конструктор смет** — строения + элементы + допы  
2. **Данные для договора**  
3. **Итог и КП**

## Элемент покраски (ядро)

На каждый элемент:
- Элементы дома: Стены / Подшива / Лобовая / Столбы / Терраса / Ограждения / Потолок / Пол / Лестница / Крыльцо / Другое
- Состояние дома: Новый|Неплёнка|Плёнка × хорошее|среднее|плохое (как матрица)
- Фильтр: Фасад / Интерьер
- Покрытие желаемое: Укрывной / Полупрозрачный
- Технология (после состояния)
- Бренд и состав ЛКМ
- Площадь м² (обязательно для попадания в смету)
- Дополнение к описанию

## Допы (аккордеоны)

Торцы · Наличники/доборы/подоконники · Прочие · Работы с ЛКМ заказчика · Доп.услуги (без скидки) · Свои работы (название+цена)

## Строения

Несколько строений на участке → блоки в смете; допы общие на объект.

## Данные для договора (шаг 2)

- Менеджер + телефон, технолог-замерщик + телефон  
- Название объекта (= имя сметы), адрес, № договора (авто ДДММГГ-N), дата, срок дней, дата старта  
- Заказчик: ФИО, телефон, почта, паспорт, кем выдан, код, адрес регистрации  
- **Цвета ЛКМ по элементам**: утверждённый цвет и/или пробники → акт согласования + план-задание  

## Итог и КП (шаг 3)

- Скидка (не на доп.услуги), НДС 5%  
- Этапы оплаты: аванс / 2 / 3 / финал (%%)  
- Документы: смета, договор, акт цвета, акт работ, план-задание  

## Чем наш замерщик дополняет конструктор

Конструктор считает от **готовой площади**.  
Замерщик: плоскости → фото сторон → материал → формула → площадь → потом в ту же логику сметы.
