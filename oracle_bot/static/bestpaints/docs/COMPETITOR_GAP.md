# Сравнение: SmartDraw / аналоги ↔ BestPaints Survey

Источники:
- [Обучение SmartDraw](https://smartdrawpro.ru/obucheniye) (уроки `sdp_1`…`sdp_51`)
- Разобраны: [sdp_4 карточка](https://smartdrawpro.ru/sdp_4), [sdp_30 быстрый расчёт](https://smartdrawpro.ru/sdp_30), [sdp_37 построение](https://smartdrawpro.ru/sdp_37)
- Аналоги: [M1 Pro](https://m1pro.ru/), [Komplekt](https://komplekt.com/), Easy Ceiling, MESTRO, Bosch MeasureOn / STABILA, Exayard

## Что делает SmartDraw (ядро из обучения)

| Блок | Суть уроков |
|------|-------------|
| **Построение** | Палец: стороны, углы, диагонали, дуги, вырезы, уровни, карниз, метки, сетка, undo, линейка, 3D, раскрой |
| **Карточка объекта** | Клиент, даты замера/монтажа, скидка, теги, воронка (думают/договоры/отмена), оплаты, менеджер/технолог, копия объекта, источник лида |
| **Несколько смет** | Для клиента / материалы / ЗП монтажников / себестоимость / дилерская |
| **Быстрый расчёт** | Без чертежа: площадь + периметр + углы + скидка → смета за минуту |
| **Отправка** | Файлы/сметы/чертежи из объекта |
| **Компания** | Номенклатура, сотрудники, доступы, мин. сумма договора, склад, календарь, архив |

App Store добавляет: **Bluetooth-линейка**, навигатор маршрута, примечание/дата договора.

## У нас уже сильнее ниши покраски

- Матрица технологий BestPaints + ЛКМ/гарантия  
- Несколько строений, фронтон/трапеция, тёплый шов, K бревна  
- Формула листа осмотра, масштаб «по проекту»  
- Готовность %, фото, цвет на схеме, PDF, Telegram/WhatsApp, PWA  

## Пробелы (приоритет для BestPaints)

### P0 — «вау как у SmartDraw», без CRM-монстра
1. **Интерактивный контур фасада** (стороны на канве: тап → длина) или хотя бы упрощённый редактор плоскостей  
2. **Быстрый расчёт** без полного замера: периметр×высота + K + % проёмов → ориентир сметы за 30 сек  
3. **Две сметы**: «клиенту» и «себестоимость / маржа»

### P1 — закрытие сделки на объекте
4. **Договор-черновик** + график оплат 10/40/40/10 + остаток  
5. **Подпись клиента** на экране / «согласовано»  
6. **Варианты «если дорого»** — пересчёт технологии/ЛКМ в один тап (уже частично есть compare tech)

### P2 — полевая скорость
7. **Bluetooth-лазер** (Web Bluetooth / ручной ввод с последнего замера)  
8. **Метки на фото** (размер поверх снимка стены)  
9. **Excel / Google Sheets** экспорт  

### P3 — команда и рост
10. Облако + роли (замерщик / офис)  
11. Календарь выездов + пуш-напоминание  
12. Воронка: думают / договор / отмена / архив  
13. AI: голос→поля, «как будет покрашено» на фото  

### Не копировать слепо
- Раскрой полотна, карниз, уровни потолка — не наш домен  
- Маркет ПВЗ / склад полотен — не сейчас  
- Полный CAD как у потолочников — дороже пользы; для фасада важнее плоскости + фронтоны (уже есть)

## Рекомендуемый следующий спринт

1. Быстрый расчёт (30 сек)  
2. Смета клиент vs себестоимость  
3. Черновик договора + оплаты  
4. (опционально) канва «нарисовать фасад сторонами»
